## Overview

This lab simulates real-world IT support workflows using a web-based ticketing system. The focus was on understanding the full ticket lifecycle, from initial creation through assignment, resolution, documentation, and closure, reflecting practices used by enterprise IT helpdesk teams.

- Simulated real-world IT support workflows using a ticketing system
- Practiced creating, assigning, resolving, and closing support tickets
- Focused on proper documentation and communication within a helpdesk environment
- Demonstrated understanding of ticket lifecycle management used in enterprise IT teams

---

## Prerequisites

- A running instance of GLPI (self-hosted or lab environment)
- Windows 10 virtual machine configured as the client
- Web browser with network access to the GLPI server
- Basic familiarity with IT support concepts and helpdesk workflows

## Key Learnings

- How IT support teams use ticketing systems to track and manage user issues efficiently
- The importance of writing clear ticket titles and detailed issue descriptions for faster resolution
- How to assign tickets and manage ticket statuses across the full lifecycle: New, Processing, Solved, and Closed
- How to document troubleshooting steps and resolutions directly within tickets for team visibility
- How proper ticket closure confirms issue resolution, supports accountability, and maintains accurate records
- Real-world scenarios practiced included Wi-Fi connectivity issues and unresponsive printer hardware

**Tickets Worked:**

- **User reported Wi-Fi connectivity issue**
  - Ticket created to document the problem
  - Issue assigned and investigated
  - Network adapter restarted and connectivity verified
  - Resolution documented in the ticket and ticket closed

- **User reported printer not responding**
  - Ticket created under the hardware category
  - Printer status reviewed and print spooler service verified
  - Troubleshooting steps recorded in ticket notes
  - Ticket marked as resolved and closed
