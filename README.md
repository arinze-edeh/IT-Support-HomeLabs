## About This Portfolio

This repository is a curated record of 13 enterprise-grade lab projects spanning IT support, systems administration, cloud infrastructure, network services, automation, observability, backup and recovery, and patch management. Every project was built from the ground up inside isolated virtual environments that mirror the architecture, tooling, and operational constraints of real production systems.

This work is not theoretical. Each lab involves provisioning, configuring, breaking, and fixing infrastructure the same way an on-call engineer would. Objectives are clearly scoped, implementations are reproducible, and failures are documented with the same rigour as successes. The goal throughout has been to build applied, job-ready technical skills across the full IT and cloud operations stack.

**What this portfolio demonstrates:**

- Structured, methodical troubleshooting across OS, network, and application layers
- Hands-on administration of Windows Server, Active Directory, Group Policy, DNS, DHCP, and Linux
- Cloud provisioning and access control across AWS and Microsoft Azure
- Monitoring, alerting, and observability using Zabbix and Wazuh
- Automation via PowerShell scripting and Linux cron scheduling
- Backup strategy design, disaster recovery validation, and patch lifecycle management
- Professional documentation at a standard where another engineer could reproduce every environment

## Project Highlights

### 01 Virtualization Lab
Stood up the entire lab foundation using VirtualBox. Resolved nine real troubleshooting issues during setup including VT-x virtualization errors, corrupted ISO handling, boot order misconfiguration, and Guest Additions installation blocked by Windows Defender. Every subsequent project runs on this environment.

### 02 and 03 Active Directory
Deployed a fully functional Windows Server 2022 domain controller from scratch. Built a structured OU hierarchy, provisioned domain users, enforced Group Policy Objects for desktop configuration and login scripts, delegated NTFS permissions, and validated policy application using gpresult /r. Diagnosed and resolved five live AD issues including DNS misconfiguration, domain join failures, and access denied errors during OU creation.

### 04 Networking Lab
Configured enterprise-grade DNS and DHCP services inside a Windows domain environment. Captured and analyzed ICMP and DNS traffic using Wireshark. Simulated a deliberate DNS misconfiguration by isolating a client from the domain DNS server, identified the root cause using ipconfig /all, and restored full resolution. Diagnosed three distinct connectivity issues caused by multiple active network adapters and incorrect adapter priority.

### 05 Windows Troubleshooting Lab
Replicated a real helpdesk escalation path: startup application failures, Event Viewer investigation, full malware scan, Print Spooler recovery, and system file repair using sfc /scannow. Windows Resource Protection detected and repaired corrupted system files, restoring full system stability. This lab directly mirrors Tier 2 IT support work.

### 06 ITSM Ticketing with GLPI
Deployed GLPI and ran a complete enterprise support simulation. Created tickets for Wi-Fi connectivity and printer issues, assigned them through the support queue, documented troubleshooting steps inside each ticket, and closed them with verified resolutions. Practiced the full ITSM lifecycle that underpins every professional helpdesk operation.

### 07 Linux Server Lab
Deployed Ubuntu Server 24.04 LTS, hardened SSH access, installed and verified Apache and Nginx web services, and configured automated cron jobs running at five-minute intervals with output logged to /tmp/cronlog.txt. Managed users and file permissions via the command line. Covers the core Linux administration skills expected at Tier 1 and Tier 2 sysadmin level.

### 08 PowerShell Automation Lab
Authored a production-quality PowerShell script that automates AD user creation at scale: creates a dedicated OU, provisions users programmatically, generates passwords as SecureString objects, checks for existing accounts before creating duplicates, and outputs clear success and failure messages. The script is idempotent and safe to re-run repeatedly without causing errors.

### 09 and 10 Cloud Fundamentals
Provisioned core infrastructure on both AWS and Azure from scratch. On Azure: Resource Groups, Virtual Machines, VNets, NSGs, Storage Accounts, and RBAC role assignment. On AWS: IAM users with scoped permissions, EC2 instances with Security Group rules, S3 buckets, and SSH-based remote access to Amazon Linux. Both deployments follow least-privilege and defence-in-depth principles.

### 11 Monitoring and Observability Lab
Deployed a full Zabbix monitoring stack on Ubuntu Server. Onboarded both a Windows 10 client and a Linux host, linked OS-specific templates, and configured threshold-based alerting for CPU, memory, and agent availability. Built a custom dashboard with live graphs and widgets. Integrated Wazuh for centralized log collection and SIEM-level analysis.

### 12 Backup and Disaster Recovery Lab
Validated a complete backup and recovery chain across three layers: OS-level System Restore, file-level File History, and full virtual machine snapshot rollback via VirtualBox. Deliberately deleted a test file, executed a snapshot restore, and confirmed the file was fully recovered with the OS booting cleanly. Documented the nuance that VirtualBox does not display restore success notifications and confirmed recovery through the snapshot tree and recovered file state.

### 13 Patch Management Lab
Simulated an enterprise patching lifecycle covering update review, deployment, validation, and rollback on both Windows and Linux. Documented the WSUS-based enterprise patching model, identified non-removable servicing stack updates, and recorded the correct procedure for rolling back problematic patches via Installed Updates in Control Panel.
